# Videntium 3D Viewer

## Description
Loads Gaussian Splatting environments in the browser.

## Tech stack
Vite
React + SWC
Typescript
Tailwind v4
Threejs + Spark

## Start development server
```
npm run dev
```


## Demo
A demo scene of Gårdstånga Kyrka is included in `public/demo/gardstanga-kyrka.sog`. Open the viewer and click **Try the demo** on the welcome screen, or **Demo: Gårdstånga Kyrka** in the sidebar.
